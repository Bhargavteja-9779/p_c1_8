# Version 1 outputs (before the internal audit)

Results, tables and figures exactly as generated by the code at commit `be46f3e` and reported in the first manuscript
draft. They are kept unchanged for transparency: an internal audit found implementation and design problems
(group reconstruction for ICRAF/Neospectra, duplicated near-interpolation path points in the RPM fit, curve-baseline
floors, single test split for small data sets, source definition), and the whole study was re-run from scratch with
the corrected code (see `CHANGELOG.md`). The originally registered RPM weighting is
re-evaluated on all new pilots as `RPM-v1`.
